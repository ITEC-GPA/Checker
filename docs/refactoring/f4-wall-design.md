# F4.10 — ricerca armature dei muri

WallReinforcementDesign coordina catalogo, filtro di capacità superiore, ammissibilità e rete secondaria sui servizi Concrete esistenti. Nessun JSON, WPF o accesso a documenti. Azioni in Nmm, spessori e armature in mm per una striscia di un metro; le verifiche puntuali sono fornite dalle sessioni Concrete già confrontate. Riutilizzate PlateDetailingRules per i minimi di rete.

Ordine storico: area crescente, poi diametro; prima proposta ammissibile. Rete di partenza Ø10 con passo 50–200 mm a multipli di 10; il dettaglio finale deve comunque essere verificato. Nessuna certificazione di un risultato privo di verifiche o con rapporti non finiti/negativi. Un rifiuto geometrico del solutore fa provare il candidato successivo; annullamento propagato senza proposta parziale.

Design 0.6.0.0: incremento del secondo componente per API nuova. 23 prove Design PASS (incluse le precedenti); ordine e aree di rete con attesi manuali, filtro meccanico, separazione soglia dettagli/prestazioni, input mancanti e annullamento prima/durante. API additive. Cattura originale in ANTHEA, 12 cataloghi congelati prima del port; adattatore e confronto completo da completare nel passo seguente.
