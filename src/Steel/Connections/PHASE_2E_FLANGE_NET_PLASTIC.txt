FIRST CONCRETE GAP
The current flange component checks gross yielding and net rupture, but not
Anet*fy/gammaM0 required for a category C tension connection. These capacities
are different: passing 0.9*Anet*fu/gammaM2 does not prove the category C check.
This addition closes that criterion for the flanges under the existing global
N-V-M distribution. It does not qualify web block tearing under general NVM.

PRIMARY SOURCE, VISUALLY VERIFIED
EN1993-1-1:2005, 6.2.3(4), equation(6.8), printed p49 / PDF p51:
Nnet,Rd = Anet*fy/gammaM0. The same page contains the distinct net rupture
equation(6.7) and the compression rule in6.2.4(3).
EN1993-1-8:2005,3.4.1(1)c, printed p21 / PDF p23: category C requires
no slip at ULS, bearing resistance and, for tension connections, the design
plastic resistance of the net section at holes. This plate check establishes
neither bolt preload nor slip performance.3.12(2) requires elastic force
distribution for category C, already used by IBeamSpliceForces.
Local source images: review-category-c-net-plastic.png, extracted from the
verified EN1993-1-1 PDF. This component does not import UK gammaM2=1.1 into NTC.

GEOMETRY, CUT AND ACTIONS
Use existing immutable IBeamSplicePlateInput and Prepare gates: two equal
aligned rolled I/H members, one external cover per flange, two transverse
bolt rows, normal round holes, no stagger/packing. X runs along the member,
Y up. Mz positive compresses the upper flange. The shared distribution first
transports actions to the splice: M0=Mz+x*Vy-y*N; then preserves the web's
share of N and M. Do not assign all moment to the flanges.
For every flange (top/bottom), separately for member and cover:
 Anet=(b-2*d0)*t; Nnet,Rd=Anet*fy/gammaM0; NEd=max(0,Nflange).
The straight net section crosses both aligned holes at any bolt column.
Longitudinal row count does not multiply holes in one transverse section.
This is net-section tensile yielding, not a combined shear/tension block path.
Member uses actual b,tf,BeamFlangeFy; cover uses its actual width,t,fy.
The single cover carries the FULL flange force, not Nflange/2. Identical
member ends have opposite external force signs but the same physical flange
tension/compression state. Compression produces zero demand for THIS check;
it does not qualify flange/cover compression or instability. No force is
discarded from the shared input, trace or other checks.

API AND FACTORS
New file IBeamSpliceFlangeNetPlastic.cs extends the existing partial
IBeamSplicePlates with VerifyFlangeNetPlastic(IBeamSplicePlateInput).
No new input wrapper; no alteration of existing production or fixture files.
Uses existing Prepare, Main, Result and SectionResistanceArithmetic.Normal.
Four checks: top/bottom x member/cover; all in N. Trace includes net/gross
area, two holes, actual d0, fy and the signed physical flange force.
Calling this method explicitly requests the category C plate criterion for
the supplied ULS combination; the method does not infer/select bolt category.
EC gammaM0 comes from the supplied policy. NTC gammaM0=1.05, with the criterion
identified as supplementary EC guidance, not a quotation of a NTC formula.
No gammaM1, gammaM2, fu or factor0.9 belongs in this resistance.

BLOCK TEARING FOLLOW-UP
The earlier source review remains valid: P358p179/EN3.10.2(2) support a first
web-cover block component under concentric longitudinal tension with two
transverse rows, interior/exterior paths and actual web share Nw/2 per cover.
It must reject nonzero V or M0; it cannot be named general NVM block tearing.
No implementation of that narrower component is included in this delivery.
