API
EndPlateInitialStiffnessFromMoment.CreateInputFromGeometry(parent,hardware)
deriva le lunghezze di tutte le file dallo stesso caso immutabile trave/nodo.
hardware contiene EndPlateBoltElongationDetail per ogni fila, ordinato per
MomentRowIndex. La lunghezza di allungamento e' quella reale di grip, rondelle
e meta' testa/dado; non e' inferita dal solo diametro nominale.
Il risultato si passa al Calculate esistente, che mantiene le verifiche di
identita', azioni, materiale, campo geometrico e lunghezza bullone.
Resta disponibile l'input con lunghezze esterne qualificate.
