WHAT IS VERIFIED
The exact N,V,M section envelope of the existing elastic concentrated-bolt
distribution, followed by a conservative longitudinal compression check of
the two identical web covers between their fasteners. Each cover carries
half the total web-bolt forces. Gross area and elastic modulus are used for
filled-hole compression; the actual bearing/net/block checks remain separate.

WHAT IS NOT VERIFIED
This component does not qualify complete N-V-M plate stability, shear buckling,
lateral torsional deformation, block tearing, load introduction, member
stability, global stiffness or the whole joint. The component is now included
in IBeamSpliceComponents with its typed WebLongitudinal result and all checks.
WEB_COVER_LOCAL_BUCKLING remains open for the other plate modes;
CanQualifyWholeJoint remains false.

EXACT SECTION ENVELOPE WITHIN THE DECLARED FORCE MODEL
The common reference frame is X along the beam, Y vertical in the web plane.
Existing bolt forces act TO THE MEMBERS. For a cut x, summing all bolts to its
left, the cover internal forces with N positive in tension can be written:
  N(x)=sum(Fx_i/2), V(x)=sum(Fy_i/2),
  M(x)=sum(((x_i-x)*Fy_i-y_i*Fx_i)/2).
N and V remain constant between columns; M is affine. Therefore the maximum
compression sigma_c=max(0,-N/A+abs(M)/W) occurs at an interval endpoint.
Both limits of EVERY bolt column are evaluated, including the moment jumps
generated by horizontal forces at different ordinates. The actual free ends
and the joint centre are also traced. No centroid moment is substituted for
the true section-force envelope of these point loads.

The implementation uses compensated prefix sums. A raw residual N,V,M is
retained at the right free edge and tested against the existing relative
equilibrium tolerance, scaled to the summed force/moment terms. No absolute
action floor is introduced. The free-edge round-off stresses do not select
a fictitious compressed strip because both free ends are unloaded by definition.
This does not eliminate or bypass the explicit residual check.

TRACE CONTRACT
Web.Longitudinal.Cut<n> exposes X, ColumnLimit, AxialForce, ShearForce, Moment,
CompressionStress and TensionStress. ColumnLimit=0 before a bolt column,
1 after it, -1 for a free-edge/joint cut. Values have N/mm/Nmm/MPa units.
Web.Longitudinal.MaximumCompression exposes X, ColumnLimit and the CONCOMITANT
N,V,M, together with the governing stress. It is not an envelope mixing the
largest N from one section with the largest M from another.
The trace also includes actual plate dimensions, pitch, Lcr, slenderness,
chi, exemption, transverse geometry screens and free-edge residuals.

LONGITUDINAL INTER-FASTENER MODEL AND VALIDITY
EN1993-1-8:2005 Table3.3 note2, printed p23/PDF p25, gives Lcr=0.6*p1.
The plate is directly contacting the member, unpacked, with filled fasteners
providing effective out-of-plane restraint. The two covers must remain identical.
No favorable butt contact or restraint across the beam end is inferred.
  p=max(longitudinalPitch,2*firstBoltDistance), Lcr=0.6*p,
  i=t/sqrt(12), lambda=Lcr/(pi*i)*sqrt(fy/E), E=210000MPa.
Solid-strip buckling curve c uses alpha0.49 through the existing shared kernel.
SCI P398 printed p57/PDF p65 gives the same strip model for flange covers and
the exemption p/t<=9*sqrt(235/fy). This longitudinal application to web covers
is explicitly an analogy/general fastener-strip component, not a new SCI
combined-web-buckling prescription.

The maximum actual elastic compression stress is conservatively imposed on
all strips uniformly for THIS longitudinal mode. Compare it with chi*fy/gammaM1
and with fy/gammaM0. In the pitch exemption use fy/gammaM0 directly. NTC keeps
its own gammaM0=gammaM1=1.05; EC gammaM1 remains explicit in the existing policy.

When compression is present, full free-outstand width/t<=14*epsilon and
inter-row width/t<=42*epsilon screen out Class4 transverse strip geometry.
Uniform compression and no subtraction of hole radii make these screens
conservative. They are geometry restrictions of this component, not evidence
of continuous line support or qualification of every possible plate mode.
For pure tension or zero actions this compression-only gate is not activated.
Shear V is retained in every section trace but has no invented buckling
interaction. General shear/lateral stability remains explicitly outside scope.

CORRECTION AFTER FIRST ROOT TEST RUN
The combined2e/4b run reported99/100 passed, with one NEW reflection assertion
wrong: changing both V and M reflects Y, so it reverses the signed cover moment
but leaves the critical longitudinal cut at x=-70 AFTER the column. The test
had incorrectly expected x=+70 BEFORE. Independent point-force statics gives:
N=-150000,V=+150000,M=+200e6 -> critical x=-70+, each-cover moment+24139551.927438.
For a true longitudinal X reflection, exchanging the left/right members in the
action convention, keep N and M unchanged and reverse ONLY V:
N=-150000,V=+150000,M=-200e6 -> critical x=+70-, each-cover moment-24139551.927438.
Both give the same maximum compression134.677756923203MPa. The original test
is renamed/corrected, and a distinct longitudinal-reflection test is added.
No production formula or published fixture was changed to make this test pass.
Root coordinates the rerun; no new test result is claimed here.
