A-TRUSS: INDEPENDENT ANALYTICAL REFERENCE
For vertical links: VRs=z q fyd c; VRc=z bw nu fcd c/(1+c^2).
For inclined links, replace c in the numerator by c+cot(alpha), and
multiply the steel branch by sin(alpha). Solving branch equality yields
c^2=bw nu fcd/[q fyd sin(alpha)]-1, then apply the admissible bounds.
These analytic extrema check the iterative EC2 optimizer independently.
Tests cover c at each bound and inside, alpha=90 and 60 degrees.
At N=0, nu=.5 for NTC and .6(1-fck/250)=.528 for base EC2, fck=30.
Torsion: TRc=2 Ak tef nu fcd c/(1+c^2), TRs=2 Ak Ast/s fyd c,
TRl=2 Ak Al/uk fyd/c. All expected geometry and capacities are computed
without calling the production resistance or geometry routines.
Combined T,V1,V2: concrete sum T/TRc+|V1|/VRc1+|V2|/VRc2;
link sum T/TRs+max(|V1|/VRs1,|V2|/VRs2), plus longitudinal capacity.
This extension is an analytical model/API check, not an independently
published biaxial torsion benchmark. It does not establish reinforcement
detailing or validate every national annex. Hollow thickness differs between
the NTC actual-wall and EC2 equivalent-wall API options; both are exercised.

A-PLASTIC: INDEPENDENT EQUILIBRIUM
Homogeneous rectangular stress block, b=200, h=400, fy=355:
Npl=b h fy, Mpl=b h^2 fy/4, M=+/-Mpl[1-(N/Npl)^2].
N is tensile-positive; M=-integral(sigma*y*dA). A pole shift to centre y0
adds -N*y0 to both signed bounds. Cases include both axial endpoints,
near endpoints, intermediate forces and y0=0/137 mm. These tests validate
the stress-block solver; they do not represent complete composite bridges.

A-MV: REFERENCE INTERACTION AND API ENVELOPE
The existing bridge reference interaction uses eta1=|M|/Mpl and
eta3=|V|/Vw, adding (1-Mf/Mpl)(2eta3-1)^2 only when eta3>.5 AND |M|>Mf.
New tabulated analytic cases probe both thresholds, each sign, and eta>1.
This extends the existing EN1993-1-5 7.1 / EN1994-2 reference tests;
no new normative clause audit is claimed here. ElasticInteraction is a
conservative library envelope with no plastic flange reserve, tested as
that policy rather than labelled an independently published example.

TOLERANCES AND LIMITS
Published values: half the last displayed unit (0.005/0.05 kN, and 0.2 kN
for four rounded studs). Analytical capacities/ratios: relative 1e-8 for
Concrete, 1e-9 for Bridge, with a unit absolute floor. Plastic domain:
absolute 1e-10*Mpl to remain meaningful at zero moment endpoints.
No expected value is generated using the function being tested. Existing
legacy fixtures and OpenSees references are not regenerated or altered.
OpenSees covers the implemented fibre laws/discretizations, not normative
coefficients or all global bridge mechanisms. Existing rollback and failed
iteration tests are retained, not duplicated merely to increase counts.
Unresolved external benchmarks remain: generic polygon/T RC N-M, PSC,
FRC experimental reproduction, M-curvature tests and independent complete
bridge examples beyond the represented fibre models; see COVERAGE.txt.
